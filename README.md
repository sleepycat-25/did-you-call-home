# **Did You Call Home?** 📞

A social accountability app that gamifies staying in touch with family and friends.

## About

**Did You Call Home?** is a web application designed to make calling home a little more fun. Users can set calling goals, compete with siblings or friends, maintain streaks, and track their progress.

The project was inspired by my own experience as a university student of sometimes putting off calling my parents as I get too busy with school.

## Planned Features

- Custom weekly calling goals
- Group competitions
- Call streaks
- Leaderboards
- Multiple competition modes
- Minimum call duration requirements
- Optional proof of calls
- Call challenges and verification
- Rewards and achievements

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
